# 3Dv

A simple and fast 3D model viewer

**Formats:** GLB, GLTF, OBJ, FBX, STL, PLY, DAE, 3DS

**Keys:** <br>
`O` options <br>
`I` info <br>
`Space` animation <br>
`L` light <br>
`R` reset view <br>
`Ctrl+O` open
